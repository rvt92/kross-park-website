# KROSS PARK website

Static site, no build step needed to deploy. Drop the folder into Netlify (drag and drop, or connect a repo).

## Editing
Pages were generated by `build.py` (shared header/footer). Either edit the HTML files directly, or edit `build.py` and rerun `python3 build.py` to keep all pages in sync. If you edit HTML directly, stop using build.py or it will overwrite your changes.

## Enquiry form
Uses Netlify Forms — works automatically once deployed on Netlify. To get submissions by email: Netlify dashboard → Site settings → Forms → Notifications.

## Fonts
Gotham Narrow self-hosted as woff2 in assets/fonts (Book 400, Medium 500, Bold 700, Black 800, Ultra 900). Licensed font — keep it on your own domain only.
